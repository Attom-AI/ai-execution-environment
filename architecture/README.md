# Architecture

This is the portable documentation layer for the execution environment. It
defines the contract implemented by `platform/` and the instance layout created
by `install.sh`.

- `directory-layout.md`: ownership and persistence boundaries
- `naming-conventions.md`: identifiers and paths
- `pipeline-and-agents.md`: work-item flow
- `state-model.md`: durable state
- `runtime-lifecycle.md`: disposable worktrees
- `scaffolding-and-intake.md`: issue intake
- `install-and-portability.md`: installation contract
- `maintaining-this-blueprint.md`: synchronization rule
