# Naming

- Workspace: stable project identifier, for example `eiakoji-me-blog`.
- Work item: source identifier, for example `ISSUE-12`.
- Worktree: globally unique flat identifier derived from both,
  `eiakoji-me-blog-issue-12`.
- Branch: `work/<workspace>/<lowercase-work-item>`.
- Canonical checkout: a relative path below `repos/`.
