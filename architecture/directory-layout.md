# Directory layout

| Path | Role | Tracked |
| --- | --- | --- |
| `architecture/` | Shareable operating contract | yes |
| `backlog/` | Platform work not tied to a project | yes |
| `documentation/` | Infrastructure and operator references | yes |
| `platform/` | Executable control-plane implementation | yes |
| `config/` | Project inventory | yes |
| `repos/` | Canonical independent repositories | no |
| `workspaces/` | Persistent project-specific work items | no |
| `worktrees/` | Flat disposable Git worktrees | no |
| `.local/` | Host-local credentials and state | no |
